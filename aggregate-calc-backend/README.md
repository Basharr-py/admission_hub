# Aggregate Calculator

A web application that calculates admission aggregate scores for Nigerian universities using university-specific admission formulas.

## Features

- University selection
- Course selection
- JAMB score calculation
- POST-UTME score calculation
- O'Level grading support
- University-specific admission formulas
- Responsive user interface

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Axios

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic
